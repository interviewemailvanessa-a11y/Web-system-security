# Web System Security

This project demonstrates a two-phase security assessment and remediation process for an Nginx web server deployed in Docker.

## Phase 1 - Security Configuration Analysis
- HTTP header analysis
- Risk identification
- Security impact assessment

See: report/analysis.md
